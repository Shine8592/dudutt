# 安全铁律与危险操作处理

> 快团团管理操作直接作用于**真实经营**。
> 本文档是硬约束，不是建议。

---

## 一、为什么需要这么严

三个事实决定了必须谨慎：

1. **没有撤销按钮**。快团团后台的「结束团」「删除团」「改价」都是一旦执行立即生效，
   官方后台**没有**"撤销上一步"功能。
2. **影响是真实的**。团一结束，正在跟团的顾客就买不了；
   价格一改，成交金额立即变化。
3. **后果由用户承担**。Agent 点错一下，损失的是用户的生意，不是 Agent 的。

所以下面的规则都是**默认拒绝、显式确认**。

---

## 二、危险操作分级

### 🔴 高危（必须逐项确认，用户明确同意才执行）

| 操作 | 位置 | 后果 |
|---|---|---|
| **删除团** | 团管理 → 删除团 | 彻底删除，**完全不可恢复** |
| **结束团** | 团管理 → 结束团 | 立即停售，顾客无法下单 |
| **修改团信息（改价）** | 团管理 → 修改团信息 | 直接改变收入 |
| 批量编辑 | 列表页 → 批量编辑 | 一次影响多个团 |
| 批量移动分类 | 列表页 → 批量移动分类 | 批量变更 |

### 🟡 中危（需说明后确认）

| 操作 | 后果 |
|---|---|
| 修改库存 | 影响可售数量；归零 = 售罄停售 |
| 帮卖团长管理 | 影响分销关系 |
| 关联供货商 | 影响供货链路 |
| 一键开团（发布） | 创建新团，会对外可见（除非存预览）|

### 🟢 低危（可直接执行）

| 操作 | 说明 |
|---|---|
| 查询 / 筛选 / 翻页 | 只读 |
| 打开团管理**菜单** | 只弹菜单，不提交 |
| 关闭弹窗（取消/知道了/Esc）| 无害 |
| 复制团 | 只是新建草稿 |
| 隐藏团 / 标记团 / 置顶 | 仅展示层面 |
| 查看操作记录 | 只读 |

## 三、高危操作标准流程

**四步，一步都不能省**：

### 第 1 步：说清要做什么

向用户报告**具体对象**（用标题，不要只用 ID）：

```
❌ 差："确认下架吗？"
✅ 好："即将结束这个团：
        【海龟爸爸防晒护肤大合集】超值买赠
        ¥39~169 · 已跟团 4 人 · 当前状态：跟团中
        结束团后顾客将无法下单，且后台没有撤销功能。
        确认要结束吗？"
```

### 第 2 步：给出改前 / 改后对比（改价类）

```
即将修改价格：
  【海龟爸爸婴童洗护大合集】
  SKU: 小样装
  改前：¥29.00
  改后：¥25.00
  差价：-¥4.00
确认要修改吗？
```

### 第 3 步：等用户明确同意

- 只有用户**明确说"确认"/"可以"/"执行"**才算同意
- 用户的沉默、模糊回应（"嗯"、"哦"）**不算同意**
- 用户改口或犹豫 → 停下，重新确认

### 第 4 步：执行后回报并提醒复核

```
✅ 已执行：团管理 → 结束团
   对象：【海龟爸爸防晒护肤大合集】超值买赠
   结果：团状态已变为「已结束」
   建议：请到后台复核确认。
```

## 四、绝对禁止清单

以下行为**任何情况下都不做**，无论用户怎么要求：

1. **不修改或删除在售商品，除非用户对那个具体对象明确确认**
   用户的"你帮我管一下"**不等于**授权你动具体某个商品。

2. **不调用后台内部接口**
   `/api/ktt_group/...`、`/api/ktt_gateway/...` 是内部私有接口。
   伪造请求 = 逆向 = 违反平台协议。只通过真实页面点击操作。

3. **不自动登录 / 不索取账号密码**
   登录由用户扫码完成。不保存 cookie 到文件，不尝试保存密码。

4. **不在用户不在场时做无人值守的写操作**
   本技能的定位是**半自动助手**，不是无人值守机器人。

5. **不用"测试"名义动真实数据**
   想验证流程 → 让**用户**决定是否新建测试团。
   Agent 不主动点任何真实商品的管理按钮。

6. **不批量执行**高危操作而不逐项确认
   即使 10 个团都要结束，也要让用户看到清单并逐项或明确整批确认。

7. **不隐藏失败**
   操作失败必须如实报告错误，不能"看起来成功了"就报成功。

## 五、误操作应急处理

### 如果不小心结束了团

- 请用户立即到后台查看该团是否可恢复
- 快团团后台部分操作有"查看操作记录"（团管理菜单内），可查看历史
- **尽快联系快团团客服**（官网底部有联系方式：`021-53395288`）

### 如果不小心改了价

- 立即用「修改团信息」改回原值
- 保留操作记录截图

### 如果不小心删了团

- 检查列表页顶部的 **「回收站」** —— 可能有恢复入口
- 若无，联系快团团客服

### 通用原则

```
立刻停止后续操作 → 如实告知用户 → 协助取证 → 建议联系官方
```

**不要试图掩盖或偷偷改回** —— 用户有权知道发生了什么。

## 六、给 Agent 的自检清单

执行任何写操作前，逐条自问：

- [ ] 我是否**只读**获取了这个对象的信息？
- [ ] 我是否**报出了对象的标题**（不是只有 ID）？
- [ ] 我是否说明了**操作的不可逆后果**？
- [ ] 我是否给出了**改前/改后对比**（若适用）？
- [ ] 用户是否**明确说了确认**？
- [ ] 我是否**没有**打算调用内部接口？
- [ ] 我是否准备了**执行后的回报**？

**有任何一条是"否" → 停下来，先补齐。**
